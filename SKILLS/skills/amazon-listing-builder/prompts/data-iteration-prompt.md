# 資料迭代提示詞

> Listing 不是一次寫完的。上線後用真實廣告和轉化資料持續最佳化。

## 🚨 資料來源優先順序（MCP > 後臺 > 瀏覽器）

| 資料 | 優先來源 | 備用來源 |
|------|---------|---------|
| 自己 ASIN 流量診斷 | `mcp__sellersprite__traffic_listing` | - |
| 自己 ASIN 出單詞 | `mcp__sellersprite__keyword_order` | - |
| 自己 ASIN 評論 | `mcp__sellersprite__review` | - |
| 價格 / BSR 歷史 | `mcp__sellersprite__keepa_info` | - |
| 價格分佈 | `mcp__sellersprite__market_price_distribution` | - |
| 廣告搜尋詞報告 | 賣家後臺（Reports → Advertising） | - |
| 客服記錄 | 賣家後臺（Buyer-Seller Messaging） | - |
| 退貨報告 | 賣家後臺（Returns） | - |
| 站外趨勢 | `mcp__sellersprite__google_trend` | `webReader(trends.google.com)` |

**禁止用瀏覽器抓 Amazon 商品頁湊資料**。所有 Amazon 站內資料走 MCP，後臺報表從賣家後臺匯出。

## 迭代週期建議

| 階段 | 頻率 | 重點 |
|------|------|------|
| 上線第 1 周 | 每天看 CTR | 標題和主圖是否吸引點選 |
| 上線 2-4 周 | 每週一次 | 詞效分析、五點最佳化 |
| 上線 1-3 個月 | 每月一次 | A+ 最佳化、QA 補充 |
| 上線 3 個月後 | 季度 | 全面重寫或精修 |

---

## 關鍵原則

1. **資料驅動** — 不要憑感覺改 Listing
2. **一次只改 1-2 個變數** — 否則不知道是哪個改動起了效
3. **保留舊版本** — 改之前先備份
4. **跟蹤 2-4 周再判斷** — 單天資料不代表趨勢

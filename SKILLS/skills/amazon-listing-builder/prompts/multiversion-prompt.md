# 多版本生成提示詞

> 用於第四到第六步：生成多版本標題/五點/描述供對比。

---

## 一、多版本標題提示詞

```
基於以下輸入，生成 3 版標題：

## 輸入
- 關鍵詞分層詞庫：[貼上 P0/P1 關鍵詞]
- 痛點-證據對映表：[貼上 Top 5 賣點]
- 品牌名：[填]
- 產品規格：[填，如 12 bundles, 16 inches]
- 合規限制：[填，如不能用絕對化表達]
- 目標站點：[填，如 US（200 字元上限）]

## 任務：生成 3 版

### 版本 1：關鍵詞覆蓋版
特點：多埋詞，結構緊湊
適用：廣告冷啟動、強競價品類

### 版本 2：轉化表達版
特點：可讀性優先，價值前置，移動端友好
適用：自然排名沉澱、移動端流量為主

### 版本 3：簡潔合規版
特點：字數剋制，無誇大表達，主詞前置
適用：高合規風險品類、新賬號

## 每版要求
1. 遵循"品牌 + 核心詞 + 差異化屬性 + 主場景 + 規格"結構
2. 字元 150-180（美國站）
3. 前 80 字元含核心詞 + 主賣點
4. 標註埋入的關鍵詞清單（對照詞庫）
5. 列出優缺點 + 適用場景

## 輸出

### 版本 1：關鍵詞覆蓋版
標題：[文字]
字元數：[X]
前 80 字元：[文字]
埋入關鍵詞：[L1/L2/L3/L5 列表]
優點：[...]
缺點：[...]
適用：[...]

### 版本 2：轉化表達版
...

### 版本 3：簡潔合規版
...

### 推薦基礎版
選擇：[版本 X]
理由：[根據品類、賬號階段、廣告策略選擇]
```

## 二、多版本五點提示詞

```
基於以下輸入，生成 2 版五點描述：

## 輸入
- 痛點-證據對映表：[貼上]
- 關鍵詞分層詞庫：[貼上]
- 使用者問題庫 Top 5：[貼上]
- 已選標題版本：[貼上]
- 合規限制：[填]

## 任務：生成 2 版

### 版本 A：轉化決策鏈版（推薦）
每點嚴格對應一個決策環節：
- Point 1：核心價值（為什麼適合主場景）
- Point 2：痛點解決（最大擔憂）
- Point 3：使用場景（具體）
- Point 4：規格使用
- Point 5：信任風險（包裝/維護）

### 版本 B：場景敘事版
每點對應一個主場景：
- Point 1：patio 場景下的體驗
- Point 2：porch 場景下的體驗
- Point 3：garden 場景下的體驗
- Point 4：planter 使用方式
- Point 5：跨場景共性賣點

## 每點要求
1. 加粗賣點標題（5-8 詞）
2. 1 句承諾 + 1-2 句證據
3. 埋入 3+ 關鍵詞（來自不同層級）
4. 字元 200-300
5. 對應一個使用者問題
6. 禁用空泛詞：premium / perfect / easy / great gift / 100% / lifetime

## 輸出
[兩版完整五點對比，每點標註埋入關鍵詞、對應問題、合規檢查]

## 對比分析
- 哪版更適合主推？
- 兩版各自的優缺點？
- 推薦基礎版及理由？
```

## 三、多版本描述/A+ 提示詞

```
基於以下輸入，生成 2 版描述 + A+ 結構：

## 輸入
- 痛點-證據對映表：[貼上]
- 五點描述（已定稿）：[貼上]
- 品牌定位：[填]
- 產品規格：[填]

## 任務

### 版本 A：故事敘事版（推薦低維護品類）
按 7 段式：
1. 開頭痛點共鳴
2. 使用場景代入
3. 產品解決方案
4. 細節對比
5. 使用步驟
6. 適合人群
7. 注意事項

### 版本 B：模組化對比版（推薦技術引數強的品類）
按 6 模組：
1. 核心賣點（3 句話總結）
2. 應用場景（4-6 個場景）
3. 規格表（表格化）
4. 使用步驟
5. 對比表（vs 普通款）
6. 注意事項

## A+ 模組（兩版共用）
- 第 1 屏：戶外場景大圖
- 第 2 屏：核心材料（如抗 UV）
- 第 3 屏：細節特寫
- 第 4 屏：場景拼圖
- 第 5 屏：規格對比
- 第 6 屏：包裝加固
- 第 7 屏：普通款 vs 升級款對比

## 輸出
- 描述版本 A + 版本 B
- A+ 7 屏結構（每屏：標題、正文、圖片需求、關鍵詞）
- 推薦版本及理由
```

---

## 使用建議

1. **多版本對比是核心** — 不要只生成一版就上線
2. **至少 3 版標題** — 因為標題對系統理解和點選率影響最大
3. **五點至少 2 版** — 一版按決策鏈、一版按場景敘事
4. **描述 2 版** — 故事版適合情感品類，模組版適合技術品類
5. **由人最終決策** — AI 列優缺點，人選基礎版

# 語義覆蓋檢查提示詞

> 檢查 Listing 是否覆蓋了 Cosmo 語義搜尋 + Alexa/Rufus 對話式購物的核心語義關係。

---

## 提示詞

```
你是一名亞馬遜語義覆蓋稽核專家。請對以下 Listing 進行語義覆蓋檢查。

## 輸入
- 完整 Listing（標題 / 五點 / 描述 / A+ / ST / QA）
- 產品類目和賣點
- 關鍵詞分層詞庫
- 使用者問題庫 Top 10

## 檢查維度

### 1. 使用者問題覆蓋（最重要）
對照問題庫 Top 10，檢查每個問題在 Listing 中是否有清晰回答：

| 問題 | 是否有回答 | 回答位置 | 評分（1-5） |
|------|----------|---------|-----------|
| Q1: Will these fade in sunlight? | ✅ | 五點 1 + QA | 5 |
| Q2: Can I use in planters? | ✅ | 五點 3 + QA | 5 |
| Q3: ... | ❌ | 缺失 | 0 |

### 2. Alexa/Rufus 自然語言問題模擬
模擬 5 個買家可能用自然語言問的問題，檢查 Listing 是否是最強匹配：

例（抗 UV 戶外模擬植物）：
- "Which artificial flowers won't fade in full sun?"
- "Can I use these in front porch planters all summer?"
- "Are there realistic-looking faux plants for outdoor use?"
- "What are good low-maintenance outdoor plants for planters?"
- "Do these artificial flowers survive rain?"

每題評估：
- Listing 是否包含所有核心意圖詞？
- 是否有具體證據支撐回答？
- 是否比競品更清晰？

### 3. 語義關係覆蓋
檢查 Listing 是否覆蓋了以下語義關係（基於 Cosmo 演算法）：

| 語義關係 | 是否覆蓋 | 在哪裡 |
|---------|---------|--------|
| 產品 → 核心品類（is-a） | ✅ | 標題 |
| 產品 → 功能屬性（has-property） | ✅ | 五點 |
| 產品 → 使用場景（used-in） | ✅ | 五點 3 + A+ 第 4 屏 |
| 產品 → 解決痛點（solves） | ✅ | 描述 + A+ 第 7 屏 |
| 產品 → 使用者人群（for-who） | ? | 描述（適合人群段落） |
| 產品 → 規格引數（has-spec） | ✅ | 五點 4 + A+ 第 5 屏 |
| 產品 → 對比差異（vs-alternative） | ? | A+ 第 7 屏 |

### 4. 任務覆蓋（Cosmo 核心概念）
列出該產品應覆蓋的使用者任務：

例（戶外模擬植物）：
- 任務 1：裝飾門廊 → 是否覆蓋？
- 任務 2：降低庭院維護 → 是否覆蓋？
- 任務 3：替代真花 → 是否覆蓋？
- 任務 4：季節裝飾 → 是否覆蓋？
- 任務 5：墓地祭奠 → 是否覆蓋？

每個任務在 Listing 中是否有場景圖 + 文字描述？

### 5. 答案型內容評分
對每個核心問題，評估答案質量（1-5 分）：

- 5 分：具體證據 + 場景邊界 + 注意事項
- 4 分：有證據，無邊界說明
- 3 分：有承諾，無證據
- 2 分：模糊回答（如 "yes, suitable for outdoor"）
- 1 分：未回答

目標：所有核心問題至少 4 分。

### 6. 移動端可讀性
- 標題前 80 字元是否含核心詞 + 主賣點？
- 五點是否每點有加粗標題（移動端只看加粗）？
- 描述段落是否短（移動端長段落會跳過）？
- A+ 是否有視覺層級？

## 輸出格式

# 語義覆蓋檢查報告

## 總分：X / 100

### 1. 問題覆蓋率：X%
- 已覆蓋：X / 10
- 缺失：[列表]

### 2. Alexa 自然語言匹配度：X / 5
[5 個問題的匹配度評估]

### 3. 語義關係覆蓋：X / 7
[每條語義關係覆蓋情況]

### 4. 使用者任務覆蓋：X / 5
[每個任務的覆蓋情況]

### 5. 答案型內容平均分：X.X / 5
[每個核心問題的評分]

### 6. 移動端可讀性：透過 / 不透過

## 缺口清單（必須補全）

| 缺口 | 優先順序 | 建議補全位置 |
|------|--------|------------|
| 任務 X 未覆蓋 | P0 | 加 A+ 第 N 屏 |
| 問題 X 評分低 | P0 | 重寫 QA Q-X |

## 最佳化建議
1. ...
2. ...
3. ...

## 是否可上架：是 / 否（需補 X 處缺口）
```

---

## 檢查時機

1. **生成 Listing 後立即跑一次**
2. **跑完合規檢查後跑語義檢查**
3. **上線後每月跑一次**（根據資料迭代）
4. **新增競品時重新評估**

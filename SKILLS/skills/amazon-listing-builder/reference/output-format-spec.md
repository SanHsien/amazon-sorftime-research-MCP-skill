# 輸出格式規範

> 所有 Listing 產出必須儲存為檔案，禁止只列印到控制檯。

---

## 一、目錄結構

```
{產品名}/
├── listing_package.md           # 完整 Listing 包（彙總）
├── keyword_library.md           # 關鍵詞分層詞庫（第一步）
├── question_library.md          # 使用者問題庫（第二步）
├── evidence_library.md          # 賣點證據庫（第三步）
├── drafts_comparison.md         # 多版本草稿對比（第四五六步）
├── audit_report.md              # 合規 + 語義 + 轉化校驗（最終）
└── input_data.json              # 原始輸入資料
```

---

## 二、檔案命名規則

| 檔案 | 命名 | 必存 |
|------|------|:----:|
| 完整 Listing 包 | `{產品英文小寫_連字元}/listing_package.md` | ✅ |
| 關鍵詞詞庫 | `keyword_library.md` | ✅ |
| 問題庫 | `question_library.md` | ✅ |
| 證據庫 | `evidence_library.md` | ✅ |
| 草稿對比 | `drafts_comparison.md` | ✅ |
| 校驗報告 | `audit_report.md` | ✅ |
| 原始資料 | `input_data.json` | ✅ |
| HTML 視覺化（可選） | `listing_package.html` | ⭐ 推薦生成 |

### 目錄命名示例
- `uv-outdoor-plants/`（抗 UV 戶外模擬植物）
- `down-filled-pillows/`（羽絨枕）
- `wireless-instruments/`（無線麥克風）

## 六、HTML 視覺化報告（推薦生成）

完成 `listing_package.md` 後，**推薦自動生成** `listing_package.html`：

### 設計要求
1. 深色專業主題、配色統一
2. 響應式適配
3. 關鍵資料用圖表（關鍵詞分佈餅圖、覆蓋率柱狀圖）
4. 單檔案 HTML + CSS + JS（無外部依賴）

### 內容覆蓋
1. **概覽** — KPI 摘要（關鍵詞數、覆蓋率、合規分數）
2. **關鍵詞分佈** — 5 層詞庫視覺化
3. **痛點-證據對映** — 關係圖
4. **標題對比** — 3 版對比卡片
5. **五點 / 描述 / QA** — 卡片式展示
6. **校驗報告** — 雷達圖（合規 / 覆蓋 / 語義 / 轉化）

> 使用者明確說"不需要 HTML"可跳過。

## 七、報告質量檢查清單

| # | 檢查項 |
|---|--------|
| 1 | 所有檔案已儲存到 `{產品目錄}/` 下 |
| 2 | 關鍵詞無 HTML 實體（`&amp;` 等） |
| 3 | 資料缺失欄位標 DATA_MISSING |
| 4 | 數值格式化（銷量千分位、價格 $X.XX） |
| 5 | 表格對齊（`:---` `:---:` `---:`） |
| 6 | 標題層級 ≤ 4 級 |
| 7 | 篩查口徑已記錄（用了哪些工具、什麼時候的資料） |
| 8 | 異常資料有 ⚠️ 標註 |

## 八、數值格式化規範

| 型別 | 格式 | 示例 |
|------|------|------|
| 銷量 | 千分位 | 12,345 |
| 銷量佔比 | 1 位小數 | 23.4% |
| 評分 | 1 位小數 | 4.2 |
| 價格 | $ + 2 位小數 | $24.99 |
| 集中度（0-1） | ×100 + 1 位小數 | 42.5% |
| 轉化率 | 1 位小數 | 6.5% |
| CPC | $ + 2 位小數 | $0.85 |
| 趨勢百分比 | + 號 + 1 位小數 | +12.5% |

## 九、關鍵鐵律

1. **禁止只列印到控制檯** — 所有產出必須儲存為檔案
2. **MD 報告完成後推薦生成 HTML** — 提升可讀性
3. **每個檔案命名一致** — 用 `keyword_library.md` 而非 `keywords.md`
4. **保留所有中間產出** — 不要只儲存最終版
5. **校驗報告必須誠實** — 不能為了讓報告好看而隱藏問題

# 痛點分類體系參考文件

本文件定義了評論分析中使用的5大痛點類別及其細分維度。

---

## 一、結構/組裝問題 (Structure & Assembly)

### 定義
與產品結構設計、組裝過程相關的問題

### 識別關鍵詞
| 關鍵詞 | 說明 |
|--------|------|
| 孔位對不上 | 預鑽孔位置不匹配 |
| 螺絲滑絲 | 螺紋損壞無法固定 |
| 安裝困難 | 組裝過程複雜 |
| 搖晃/不穩 | 組裝後結構不穩固 |
| 抽屜卡頓 | 抽屜滑動不暢 |
| 缺少配件 | 包裝內零件缺失 |
| 說明書不清 | 組裝指導不明確 |

### 嚴重程度判斷標準
| 程度 | 標準 | 示例 |
|------|------|------|
| 高 | 無法正常使用/安全隱患 | "櫃子散架"、"完全裝不起來" |
| 中 | 可用但體驗差 | "抽屜有點卡"、"安裝花了2小時" |
| 低 | 輕微問題 | "少了一個螺絲但客服補發了" |

### 根源分析方向
| 維度 | 檢查點 | 改進建議 |
|------|--------|----------|
| 設計 | 公差是否合理 | 最佳化孔位公差 |
| 生產 | 質量控制 | 加強來料檢驗 |
| 包裝 | 配件清單檢查 | 包裝內附配件清單 |

---

## 二、電子模組故障 (Electronics Malfunction)

### 定義
產品中電子部件功能失效問題

### 識別關鍵詞
| 關鍵詞 | 說明 |
|--------|------|
| USB沒電 | USB埠無輸出 |
| 充電慢 | 充電速度異常 |
| 插孔鬆動 | 介面接觸不良 |
| LED不亮 | 燈帶故障 |
| APP閃退 | 軟體崩潰 |
| 藍芽/Wi-Fi失敗 | 無線連線問題 |

### 嚴重程度判斷標準
| 程度 | 標準 | 示例 |
|------|------|------|
| 高 | 核心功能完全失效 | "燈完全不亮"、"充不進電" |
| 中 | 功能間歇性失效 | "有時候連不上藍芽" |
| 低 | 使用體驗不佳 | "APP操作有點複雜" |

### 根源分析方向
| 維度 | 檢查點 | 改進建議 |
|------|--------|----------|
| 設計 | 電路設計是否合理 | 增加過載保護 |
| 供應 | 電子元件質量 | 更換供應商 |
| 軟體 | APP相容性 | 適配新系統版本 |

## 三、設計/功能缺陷 (Design & Functional Flaws)

### 定義
產品功能設計不合理導致的使用問題

### 識別關鍵詞
| 關鍵詞 | 說明 |
|--------|------|
| 抽屜淺 | 儲物空間不足 |
| 燈光刺眼/太暗 | 照明效果差 |
| 儲物不夠 | 容量設計不足 |
| 線路雜亂 | 電線收納設計差 |

### 嚴重程度判斷標準
| 程度 | 標準 | 示例 |
|------|------|------|
| 高 | 基本功能無法滿足 | "抽屜淺得放不進A4紙" |
| 中 | 功能受限 | "儲物格只放得下幾個小物件" |
| 低 | 使用不便 | "電線有點難整理" |

### 根源分析方向
| 維度 | 檢查點 | 改進建議 |
|------|--------|----------|
| 設計 | 使用者需求調研 | 增加儲物深度 |
| 測試 | 實際使用場景測試 | 最佳化照明亮度 |

## 四、外觀/材質問題 (Appearance & Material)

### 定義
產品外觀和材質相關的問題

### 識別關鍵詞
| 關鍵詞 | 說明 |
|--------|------|
| 劃痕/磕碰 | 運輸損壞 |
| 色差 | 顏色與描述不符 |
| 異味/甲醛 | 材料氣味問題 |
| 生鏽 | 金屬防鏽問題 |
| 起泡/貼皮掉 | 表面處理問題 |

### 嚴重程度判斷標準
| 程度 | 標準 | 示例 |
|------|------|------|
| 高 | 健康隱患 | "味道很大，頭暈" |
| 中 | 明顯外觀缺陷 | "色差很明顯" |
| 低 | 輕微瑕疵 | "有個小劃痕" |

### 根源分析方向
| 維度 | 檢查點 | 改進建議 |
|------|--------|----------|
| 材料 | 環保材料選擇 | 使用E1級板材 |
| 包裝 | 運輸保護 | 加強角部保護 |
| 生產 | 表面處理工藝 | 改進塗裝工藝 |

## 五、描述不符 (Description Mismatch)

### 定義
產品實際情況與Listing描述存在偏差

### 識別關鍵詞
| 關鍵詞 | 說明 |
|--------|------|
| 比想象中小 | 尺寸預期偏差 |
| 顏色不一樣 | 顏色預期偏差 |
| 材質不是 | 材料預期偏差 |
| 功能很難用 | 功能預期偏差 |

### 嚴重程度判斷標準
| 程度 | 標準 | 示例 |
|------|------|------|
| 高 | 核心功能與描述不符 | "說有智慧功能根本用不了" |
| 中 | 尺寸/顏色偏差大 | "比圖片小很多" |
| 低 | 輕微預期差異 | "稍微小一點但還能用" |

### 根源分析方向
| 維度 | 檢查點 | 改進建議 |
|------|--------|----------|
| Listing | 描述準確性 | 修改誇大描述 |
| 圖片 | 圖片真實性 | 新增實物對比圖 |
| 尺寸 | 尺寸展示 | 提供場景參照 |

## 分類流程圖

```
評論文字
    │
    ├─ 包含"孔位/螺絲/安裝/搖晃" → 結構/組裝問題
    │
    ├─ 包含"USB/充電/燈/APP/藍芽" → 電子模組故障
    │
    ├─ 包含"淺/不穩/刺眼/收納" → 設計/功能缺陷
    │
    ├─ 包含"劃痕/色差/異味/生鏽" → 外觀/材質問題
    │
    ├─ 包含"小/不一樣/不是" → 描述不符
    │
    └─ 無匹配 → 其他
```

---

## 使用說明

1. **優先順序判斷**: 當評論同時涉及多個類別時，按嚴重程度高者優先

2. **置信度計算**:
   - 匹配1個關鍵詞: 0.5
   - 匹配2個關鍵詞: 0.7
   - 匹配3+關鍵詞: 0.9

3. **邊界情況處理**:
   - "抽屜淺且卡頓" → 同時記錄設計缺陷和結構問題
   - "燈不亮且有異味" → 同時記錄電子故障和材質問題

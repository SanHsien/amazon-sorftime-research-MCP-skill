# LLM Prompt 模板庫

本文件提供 product-research Skill 中使用的 Prompt 模板，供 LLM 執行各分析步驟時參考。

---

## 模板 1: 屬性標註

### 使用場景

Step 2: 屬性標註階段 - LLM 從 Top100 產品標題中提取關鍵差異化維度

### Prompt 模板

```markdown
你是一位產品分析專家，擅長從產品標題中識別關鍵差異化維度。

## 任務目標

分析以下 Top100 產品標題，提取 3-6 個關鍵差異化維度。

## 分析樣本

### 前 20 個產品標題樣本：
{titles_sample}

### 分析要求

1. **識別差異化維度**（3-6 個）
   - 維度應該是該品類的關鍵差異化因素
   - 如：電子產品的功率、容量、防水等級；家居產品的材質、尺寸、風格等
   - 避免通用維度（如顏色、包裝）

2. **為每個產品標註維度值**
   - 從標題中提取資訊
   - 如果標題中缺失，標註為"未知"
   - 標註置信度：高（標題明確）、中（需要推斷）、低（缺失/不確定）

3. **維度值分類**
   - 每個維度的值應該是可分類的
   - 如：功率 -> 20W/30W/65W/100W+
   - 如：防水 -> IPX7/IPX5/無

## 輸出格式

### 維度定義表

| 維度名稱 | 說明 | 候的分類 |
|---------|------|---------|
| 功率 | 輸出功率 | 20W以下 / 20-30W / 30-45W / 45-65W / 65W+ |
| 防水 | 防水等級 | IPX7+ / IPX5-6 / 無 |
| ... | ... | ... |

### 標註結果示例

| ASIN | 標題 | [維度1] | [維度2] | ... | 置信度 |
|------|------|---------|---------|-----|--------|
| B0XXX | 產品標題... | 20W | IPX7 | ... | 高 |
```

## 模板 2: 交叉分析

### 使用場景

Step 3: 交叉分析階段 - LLM 從已標註資料中發現供需缺口

### Prompt 模板

```markdown
你是一位市場機會分析師，擅長從資料中發現供需缺口和市場機會。

## 任務目標

基於已標註的 Top100 產品資料，執行交叉分析，發現未被滿足的市場需求。

## 輸入資料

### 已標註產品資料（部分樣本）
{annotated_products_sample}

### 市場概況
- Top100 月銷量: {monthly_sales}
- Top100 月銷額: {monthly_revenue}
- 平均價格: ${avg_price}

## 分析要求

### 1. 選擇維度組合
- 選擇 2-3 對有意義的維度組合
- 考慮因素：
  - 維度之間的關聯性（如：功率×價格、防水×場景）
  - 市場需求合理性
  - 資料完整性

### 2. 識別供需狀態
對每個維度組合，識別：
- **空白點**：產品數 = 0
- **薄供給**：產品數 ≤ 2
- **高需求低供給**：月銷量高但產品數少

### 3. 原因分析
對每個空白/薄供給，分析：
- 技術限制（無法實現或成本過高）
- 需求不存在（消費者不需要）
- 被市場忽視（存在但未被滿足）
- 供應鏈難度

### 4. 機會評級
按三維評估排序：
- 市場規模（40%）：月銷額 $100K+ = 高，$50K-100K = 中，<$50K = 低
- 技術可行性（30%）：現有產品線 = 高，需新模具 = 中，需研發 = 低
- 品牌匹配（30%）：核心優勢 = 高，部分匹配 = 中，全新領域 = 低

## 輸出格式

### 交叉分析矩陣

| 維度A × 維度B | 狀態 | 產品數 | 月銷量 | 均價 | 原因分析 | 機會評級 |
|--------------|------|--------|--------|------|----------|---------|
| 65W × $50-80 | 薄供給 | 1 | 2000 | $70 | 技術可行但被忽視 | 高 |
| ... | ... | ... | ... | ... | ... | ... |

### 關鍵發現
- 哪些組合是市場主力？（高供給 + 高需求）
- 哪些組合存在明顯空白？
- 哪些空白值得進入？
```

## 模板 3: 競品選擇邏輯

### 使用場景

Step 4: 競品與 VOC 分析 - LLM 按細分段選擇代表性競品

### Prompt 模板

```markdown
你是一位競品分析專家，需要選擇代表性競品進行深度分析。

## 任務目標

從 Top100 產品中選擇 6-10 個代表性競品，用於差評分析和策略制定。

## 輸入資料

### Top100 產品資料（部分樣本）
{top100_sample}

### 已標註維度
{dimensions_summary}

## 選擇要求

### 必須覆蓋的細分段

1. **量級標杆**（1-2 個）
   - Top3-5 銷量產品
   - 代表市場標準

2. **功能差異代表**（每個主要維度 1 個）
   - 各維度的頭部產品
   - 如：高功率代表、防水等級代表

3. **價格帶覆蓋**（高/中/低各 1 個）
   - 高價段：> 平均價 30%
   - 中價段：平均價 ± 20%
   - 低價段：< 平均價 30%

4. **痛點參考**（1-2 個）
   - 差評率高或評分低的產品
   - 用於挖掘改進機會

## 輸出格式

| ASIN | 品牌 | 選擇理由 | 競品型別 | 覆蓋維度 | 價格 | 月銷量 | 評論數 |
|------|------|----------|----------|----------|------|--------|--------|
| B0XXX | BrandA | 類目 Top3，覆蓋主力價格帶 | 量級標杆 | 價格-中 | $XX | XXXX | XXX |
| ... | ... | ... | ... | ... | ... | ... | ... |
```

## 模板 4: 差評維度歸類

### 使用場景

Step 4: 競品與 VOC 分析 - LLM 按屬性維度歸類差評痛點

### Prompt 模板

```markdown
你是一位產品開發顧問，擅長從使用者評論中挖掘產品痛點和改進機會。

## 任務目標

將競品差評按屬性維度歸類，並對映到品牌能力和產品方案。

## 輸入資料

### 競品選擇邏輯表
{competitor_selection}

### 差評樣本（部分）
{reviews_sample}

## 歸類要求

### 按屬性維度（而非按產品）歸類

1. **識別主要維度**（3-6 個）
   - 基於差評內容提取痛點類別
   - 如：續航/電池、功率/充電、數顯、線材、外觀、質量等

2. **每個維度包含**
   - 痛點描述：使用者不滿的具體問題
   - 頻次/佔比：涉及多少條差評
   - 涉及競品：哪些品牌/產品有此問題
   - 品牌機會：我們的品牌/供應鏈能如何解決
   - 產品方案：具體的產品改進方向

### 痛點→方案對映

| 要素 | 說明 | 示例 |
|------|------|------|
| 痛點描述 | 使用者不滿的具體問題 | "電池容量虛標，實際續航不足 50%" |
| 資料支撐 | 差評頻次/佔比 | "涉及 45 條差評，佔比 32%" |
| 品牌機會 | 品牌/供應鏈能力 | "有高密度電芯供應鏈" |
| 產品方案 | 具體改進方案 | "4000mAh 實標 + 實測影片營銷" |

## 輸出格式

### 差評維度歸類表

| 維度 | 痛點 | 頻次 | 佔比 | 涉及競品 | 品牌機會 | 產品方案 |
|------|------|------|------|----------|----------|----------|
| 續航/電池 | 容量虛標 | 45 | 32% | BrandA,B | 高密度電芯 | 4000mAh 實標 |
| ... | ... | ... | ... | ... | ... | ... |
```

## 模板 5: 選品決策評估（五維評分）

### 使用場景

Step 5: 評估與決策 - LLM 進行量化評分並給出決策

### Prompt 模板

```markdown
你是一位投資決策專家，需要基於市場資料進行選品決策量化評分。

## 任務目標

對選品機會進行五維加權評分，給出明確的進入決策建議。

## 評分體系

| 維度 | 權重 | 評分標準 (1-10) | 資料來源 |
|------|------|---------------|----------|
| 市場規模 | 20% | 月銷額>$10M=10, >$5M=8, >$1M=6, 其他=4 | Top100 月銷額 |
| 競爭格局 | 25% | CR3<30%=10, <50%=7, 其他=4 | CR3 + 新品佔比 |
| 需求清晰度 | 15% | 關鍵詞+交叉分析明確=10, 較明確=7, 模糊=4 | 關鍵詞資料 + 交叉分析 |
| 進入壁壘(反) | 20% | 低壁壘=10, 中=6, 高=3 | 六類壁壘評估 |
| 盈利能力 | 20% | 毛利>40%=10, >30%=8, >20%=6, 其他=4 | 成本測算 |

## 決策矩陣

| 加權總分 | 決策結論 | 詳細說明 |
|----------|----------|----------|
| 7.5-10 | **建議進入** | 優先推進，快速執行 |
| 6.0-7.4 | **謹慎進入** | 需精準定位細分市場，明確准入條件 |
| 4.0-5.9 | **暫緩觀望** | 需更多資料驗證，或等待時機 |
| 0-3.9 | **不建議進入** | 風險大於機會，放棄 |

## 輸入資料

### 市場概況
{market_overview}

### 競爭格局
{competition_summary}

### 交叉分析
{cross_analysis_summary}

### 進入壁壘
{barriers_summary}

### 成本測算
| 專案 | 金額 |
|------|------|
| 採購成本 | $XX |
| FBA 費用 | $XX |
| 頭程物流 | $XX |
| 預估毛利 | $XX |
| 預估毛利率 | XX% |

## 輸出格式

### 選品決策評估表

| 維度 | 權重 | 評分(1-10) | 加權分 | 依據 |
|------|------|-----------|--------|------|
| 市場規模 | 20% | [評分] | [分數] | [資料依據] |
| 競爭格局 | 25% | [評分] | [分數] | [資料依據] |
| ... | ... | ... | ... | ... |
| **總分** | 100% | - | **[總分]** | - |

### 決策結論

- **決策**: 建議進入 / 謹慎進入 / 暫緩觀望 / 不建議進入
- **綜合得分**: [X.XX]/10
- **核心洞察**: [2-3句話總結]

### 詳細說明

**准入條件** (如適用):
1. [必須滿足的條件1]
2. [必須滿足的條件2]
...

**禁止進入**:
- [明確禁止的場景]

**風險提示**:
- [關鍵風險及緩解方案]
```

## 模板 6: 產品矩陣規劃

### 使用場景

Step 5: 評估與決策 - LLM 規劃具體產品矩陣

### Prompt 模板

```markdown
你是一位產品經理，需要基於分析結果規劃具體的產品矩陣。

## 任務目標

規劃 Tier 1（必須）和 Tier 2/3（可選）產品的具體規格。

## 輸入資料

### 機會優先順序
{opportunities_ranking}

### 供需缺口
{gaps_summary}

### 痛點分析
{pain_points_summary}

## 產品矩陣要求

### Tier 1 產品（必須完整具體）

### 結構模板

```
### Tier 1: [產品定位一句話]

**目標市場**：[維度組合空白/機會，如：65W + 數顯 + $50-80 價格帶]
**決策理由**：[基於 cross_analysis ch04 + pain_points ch06 的資料]

| 維度 | 規格 | 決策依據 |
|------|------|----------|
| [維度1] | [具體值] | [為什麼選這個值 - 引用資料] |
| [維度2] | [具體值] | [為什麼選這個值 - 引用資料] |
| ... | ... | ... |

**目標定價**：$XX.XX（基於 Step 5 測算，毛利率 XX%）
**差異化主張**：[一句話核心賣點，區別於競品]
**對標競品**：[ASIN] [品牌] $XX — 我們的優勢：[具體差異]
**預估月銷潛力**：XX-XX 件/月（基於同組合競品表現推算）
```

### ⛔ 硬性要求

1. **禁止佔位語**：
   - ❌ "待確認"、"待定"、"建議進一步調研"
   - ✅ 具體數值和明確依據

2. **必須包含的欄位**：
   - 目標市場（維度組合空白）
   - 決策理由（資料依據）
   - 完整規格表（維度×規格×依據）
   - 目標定價（基於成本測算）
   - 差異化主張（一句話）
   - 對標競品（具體 ASIN）
   - 預估月銷潛力（基於資料推算）

### Tier 2/3 產品（可選）

如果有多個高價值機會，規劃 Tier 2/3：
- 簡化規格（只列出關鍵差異化維度）
- 預估優先順序（何時進入）
```

## 使用指南

### 在 SKILL.md 中引用

```markdown
### Step 2: 屬性標註

使用 LLM Prompt 模板 [屬性標註] 進行維度提取：

> 請參考 `references/prompt_templates.md` 中的 [模板 1: 屬性標註] 對以下產品標題進行維度標註...

### Step 3: 交叉分析

使用 LLM Prompt 模板 [交叉分析] 發現供需缺口：

> 請參考 `references/prompt_templates.md` 中的 [模板 2: 交叉分析] 對已標註資料進行分析...
```

### 動態調整

根據品類特徵調整模板：
- **電子產品**：維度通常包括功率、容量、防水、介面型別等
- **家居產品**：維度通常包括材質、尺寸、風格、顏色等
- **服裝配飾**：維度通常包括材質、尺碼、風格、季節等

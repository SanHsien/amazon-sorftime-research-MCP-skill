# 買家評論洞察

深度分析買家評論，提煉痛點和改進方向。

## 使用方式

```
/review-insights [ASIN] [站點]
```

## 工具呼叫

`mcp__sellersprite__review` — 扁平引數 `{"marketplace":"US", "asin":"B0XXX"}`

**響應解析**：`result.content[0].text` 是 JSON 字串，需二次解析。

## ⚠️ review 工具限制

- **每次最多返回 20 條**（size=100 也被限制為 20）
- 評分分佈是**樣本**，不代表總體
- 報告中必須註明："僅展示最近 20 條評論，不代表總體分佈"
- 實際欄位：`content`（非 `body`）、`date`（非 `createTime`）

## 執行步驟

### 第1步: 獲取評論資料

呼叫 `mcp__sellersprite__review` 獲取 ASIN 評論資料。

### 第2步: NLP 分類分析

自行對評論內容進行 NLP 聚類：正面/負面/中性，提取痛點關鍵詞。

### 第3步: 儲存結果 + 生成報告

同時儲存原始資料和報告到 `{類別目錄}/`。

**報告結構：** 評論概覽（註明抽樣限制）→ 好評關鍵詞 → 差評痛點頻次 → 改進建議 → 競品評論對比（如有）
